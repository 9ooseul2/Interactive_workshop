# Sampler sound files

Place one audio file per pad in this folder. Use the lowercase key as the filename:

- `q.wav` or `q.mp3`
- `w.wav` or `w.mp3`
- `e.wav` or `e.mp3`
- `a.wav` or `a.mp3`
- `s.wav` or `s.mp3`
- `d.wav` or `d.mp3`
- `z.wav` or `z.mp3`
- `x.wav` or `x.mp3`
- `c.wav` or `c.mp3`

When both formats exist, the WAV file is loaded first. If neither file exists, the sampler uses its built-in synthesized sound so every pad remains playable.
